# himachat-AI-ChatBot
This repository is for creating AI chatbots with himachat.<br>
# How to use
Just open the developer tools in your PC's browser or Android's Kiwi Browser and run it in the console tab.<br>
If you're planning on running this on an iPhone, add the following shortcut: [How to use the console on your iPhone](https://laptopreneur.net/%E3%82%B9%E3%83%9E%E3%83%9B-%E3%82%B3%E3%83%B3%E3%82%BD%E3%83%BC%E3%83%AB/)
Please change the settings yourself.
